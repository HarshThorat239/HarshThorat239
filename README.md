## 🏆 Highlights

- 🤖 **iRobi v2** — Reverse-engineered a discontinued Korean healthcare robot and rebuilt it around a Raspberry Pi 4 + ROS 2: six motors over I²C, custom SPI display drivers, onboard camera, and a fully internal 65 W power system
- 🧠 **Rainbow DQN Pokémon agent** — Deep RL agent (Double/Dueling DQN, prioritised replay, NoisyNet, distributional Q-learning) hitting a **93% win rate**; a companion rule-based expert system reached **98%** against a Smogon meta team
- 🏎️ **EVolocity telemetry ECU** — Led firmware for a real-time energy-monitoring ECU on the Pi Pico W (25 Hz sampling, sub-1% accuracy, fault-tolerant HTTPS uploads) — **top-10 nationally** for energy-monitoring accuracy
- 🔬 **HMPSoC** — Heterogeneous multiprocessor SoC on a Cyclone V FPGA with custom VHDL DSP processors, a hand-built RISC control processor, and a TDMA NoC, closing timing at **94.63 MHz**
- 👋 **Sign-SYS** — Real-time NZSL gesture recognition with CNNs (95% accuracy) for accessible human-computer interaction
